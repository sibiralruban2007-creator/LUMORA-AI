## Project Overview

LUMORA AI is an AI-powered Intelligent Learning Assistant designed to make learning easier, smarter, and more effective.

It provides a digital learning workspace where students can generate study notes, practice quizzes, and understand difficult topics through Artificial Intelligence.

The application is developed using Python and Streamlit, with AI integration planned through the Groq API.

## Objectives

- Make learning simple and effective.
- Generate easy-to-understand study notes.
- Help students practise through quizzes.
- Explain complex concepts in simple English.
- Provide an interactive learning dashboard.

## Features

### 1. AI Notes Generator
Generate simplified study notes from academic topics.

### 2. AI Quiz Generator
Create practice questions to test students' knowledge.

### 3. AI Topic Explainer
Understand difficult concepts through simple explanations.

### 4. Learning Dashboard
Access all learning tools from one interactive dashboard.

## Installation and Setup

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the project folder**

```bash
cd LUMORA-AI
```

**Step 3: Create a virtual environment**

```bash
python -m venv .venv
```

**Step 4: Activate the environment**

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

**Step 5: Install Streamlit**

```bash
pip install streamlit
```

**Step 6: Run the application**

```bash
python -m streamlit run app.py
```
